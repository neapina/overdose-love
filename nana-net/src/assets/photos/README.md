# Свои фотографии

Положи сюда картинку с именем = id фото из `src/story/photos.ts`, и она заменит нарисованную заглушку.

Пример: `sky_1.jpg`, `room_1.png`, `mayu_1.jpg`, `ren_1.jpg`, `cafe_mayu.jpg`, `river_nana.jpg`, `sea_1.jpg`.
Снимки с вебки: `webcam_1.jpg`, `webcam_2.jpg`, …

Форматы: jpg / jpeg / png / webp. Пересборка не нужна — Vite подхватит сам.
